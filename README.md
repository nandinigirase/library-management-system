# library-management-system

## About the Project
The Library Management System is a web application
developed to simplify library operations.

## Technologies Used
- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
- HTML
- CSS
- Bootstrap

## Features
- Book Management
- Member Management
- Issue and Return Books
- Admin Dashboard
- Search and Filter Books
- Responsive User Interface

## Installation

1. Clone the repository.
2. Open the project folder in VS Code.
3. Install dependencies:

   npm install

4. Create a .env file with the required configuration.
5. Start the application:

   npm start

   If no start script is configured, use:
   node server.js

6. Open the local URL displayed by your server.
